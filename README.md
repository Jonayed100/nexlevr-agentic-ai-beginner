# NEXLEVR Agentic AI Developer Internship - Beginner Track

My work for the Beginner track of the
[NEXLEVR](https://www.nexlevr.app/resources/agentic-ai-developer) Agentic AI
Developer internship (Nov 15 - Dec 15, 2026).

| Task | What it is | Folder |
|------|------------|--------|
| 1. Your first tool-using AI | A model answers price questions by calling one function that reads a local file | [`task1-first-tool-agent`](task1-first-tool-agent) |
| 2. Daily trends digest agent | An agent reads 5 tech news feeds and writes a 5-bullet digest with source links and post ideas | [`task2-trends-digest-agent`](task2-trends-digest-agent) |
| 3. Workflows vs agents | A design doc with 3 business examples and a recommendation for each | [`task3-workflows-vs-agents`](task3-workflows-vs-agents) |

Both scripts use only the Python standard library and work with any
OpenAI-compatible chat API that supports tool calling. Each folder's README
explains how to run it and how it works, step by step.

**Skills practised:** Python, tool use / function calling, the agent loop,
guardrails, and choosing between workflows and agents.
